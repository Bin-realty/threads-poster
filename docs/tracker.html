連上你的 GitHub

跟 Threads-Bin 用同一把鑰匙，貼一次就好。它只存在這台裝置的瀏覽器裡，頁面直接跟 GitHub 溝通，不經過任何人。

  1. GitHub → 頭像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository access：Only select repositories → 勾 threads-poster 和 realty-data
  3. Permissions → Repository permissions → Contents：Read and write
  4. 複製鑰匙，貼在下面

打字或用手機鍵盤語音都可以。按「整理」後會先打開客戶卡給你確認，改到需求的欄位會標出來，不會直接存。
