  1. GitHub → 頭像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access：Only select repositories → threads-poster
  3. Permissions → Repository permissions → Contents：Read and write
  4. 產生後複製，貼在下面
