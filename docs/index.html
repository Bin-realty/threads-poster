第一次使用：貼上 GitHub 鑰匙

鑰匙只存在這台裝置的瀏覽器裡，直接跟 GitHub 溝通，不會傳到別的地方。換手機或電腦要再貼一次。

  1. GitHub → 右上頭像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access 選 Only select repositories → threads-poster
  3. Permissions → Repository permissions → Contents：Read and write
  4. 有效期限選 1 年 → 產生後複製，貼在下面
